# CosmoQMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build CosmoQMS — a multi-tenant MES/QMS (Manufacturing Execution + Quality Management) web app for a cosmetics lab, from scratch, following `cosmoqms-blueprint.md` exactly, ready to deploy to Vercel + Supabase.

**Standalone-but-modular:** This is a **separate project**, scaffolded as a sibling directory to `programa_Cosmetico_Mariposa` (its own folder, its own git repo, its own Supabase project, its own Clerk app) — nothing in Mariposa ERP (`server/`, `client/`) is touched by this plan, and CosmoQMS has zero runtime dependency on it today. "Modular for future integration" is designed in from Task 2 onward, not bolted on later: (1) `organizations` (the tenant table, Task 2) means Mariposa's single lab can become tenant #1 of CosmoQMS later with a data migration, not a schema rewrite; (2) every domain module (`materials`, `formulas`, `production`, `qc`, `deviations`, `traceability`, `audit` — one tRPC router per domain, Task 6 onward) is self-contained with no cross-router imports, so a future integration can adopt modules one at a time (e.g. point CosmoQMS's `traceability` at Mariposa's data via a read adapter) instead of an all-or-nothing cutover; (3) the Prisma schema uses the same entity vocabulary as Mariposa's (`raw_materials`≈`Insumo`, `production_orders`≈`OrdenProduccion`) so a future data-migration script has an obvious field mapping instead of a from-scratch translation layer. None of this requires any action now — it's a constraint on how Tasks 2–19 are built, called out per-task where it matters.

**Architecture:** Next.js 15 App Router monolith. Server Components read Prisma directly for listings/reports; interactive screens (batch record, forms) use tRPC + TanStack Query. Clerk Organizations provide auth + tenant identity; every Prisma query runs inside a transaction that sets `app.current_tenant_id`, enforced again at the DB layer by Postgres Row Level Security. Plant-floor capture writes first to a local Dexie (IndexedDB) queue keyed by a client-generated `clientEventId`, and a sync engine pushes it to `/api/sync/events` on reconnect — append-only, idempotent, never overwritten. Every mutation on a regulated table is wrapped by a Prisma Client Extension that writes an `audit_log` row in the same transaction.

**Tech Stack:** Next.js 15 (App Router) + TypeScript strict + Tailwind CSS v4 + shadcn/ui + PostgreSQL (Supabase, region `sa-east-1`) + Prisma + Clerk (Organizations + MFA) + tRPC + TanStack Query/Table + Zustand (UI-only) + Serwist (PWA) + Dexie.js (offline queue) + Playwright (server-side PDF) + Zod + react-hook-form + pnpm.

## Global Constraints

- `batch_events` is append-only — never `UPDATE`/`DELETE`, only `INSERT`. A correction is a new compensating event.
- Every mutation on a regulated table (`production_orders`, `batch_events`, `qc_results`, `deviations`, `finished_product_lots`) must write to `audit_log` in the same transaction; if the audit write fails, the mutation fails.
- No electronic signature persists without `reauth_verified = true` and an explicit `meaning_statement`.
- Every query must respect Row Level Security by `tenant_id`. The Supabase `service role` key is used only in webhooks/migrations, never in a user-facing route.
- TypeScript strict, zero `any`.
- A `master_formulas` row can only be set `status = active` if its ingredients sum to 100% ± configurable tolerance.
- Offline events use a device-generated `clientEventId`; the server must ignore duplicates (`ON CONFLICT DO NOTHING`), never apply twice.
- Batch stage transitions are validated server-side as a state machine — the client's reported state is never trusted.
- Mobile-first, touch targets ≥44×44px, contrast ≥4.5:1 in light and dark, Lucide SVG icons, never emoji.
- One component per file, max 300 lines — extract subcomponents if it grows.
- Path alias `@/` → `src/`. No barrel exports — import directly from source files.
- Server Components by default; `"use client"` only where there is real interactivity.
- Never commit `.env` files.

- [ ] **Step 2: Write `src/lib/db.ts`**

```typescript
import { PrismaClient, Prisma } from "@prisma/client";

const globalForPrisma = globalThis as unknown as { prisma?: PrismaClient };

export const prisma = globalForPrisma.prisma ?? new PrismaClient();

if (process.env.NODE_ENV !== "production") {
  globalForPrisma.prisma = prisma;
}

export async function withTenant<T>(
  tenantId: string,
  fn: (tx: Prisma.TransactionClient) => Promise<T>,
): Promise<T> {
  return prisma.$transaction(async (tx) => {
    await tx.$executeRawUnsafe(
      `SET LOCAL app.current_tenant_id = '${tenantId}'`,
    );
    return fn(tx);
  });
}
```

```typescript
import { auth } from "@clerk/nextjs/server";
import { prisma } from "@/lib/db";
import type { Role } from "@prisma/client";

export type CurrentUser = { id: string; tenantId: string; role: Role };

export async function getCurrentUser(): Promise<CurrentUser | null> {
  const { userId, orgId } = auth();
  if (!userId || !orgId) return null;
  const user = await prisma.user.findUnique({ where: { id: userId } });
  if (!user || !user.active || user.tenantId !== orgId) return null;
  return { id: user.id, tenantId: user.tenantId, role: user.role };
}

export class UnauthorizedError extends Error {}
export class ForbiddenError extends Error {}

export async function requireRole(allowed: Role[]): Promise<CurrentUser> {
  const user = await getCurrentUser();
  if (!user) throw new UnauthorizedError("No hay sesion activa");
  if (!allowed.includes(user.role)) throw new ForbiddenError(`Rol ${user.role} no autorizado`);
  return user;
}
```

```typescript
import { initTRPC, TRPCError } from "@trpc/server";
import superjson from "superjson";
import type { TRPCContext } from "./context";
import type { Role } from "@prisma/client";
import { withTenant } from "@/lib/db";

const t = initTRPC.context<TRPCContext>().create({ transformer: superjson });

export const router = t.router;
export const publicProcedure = t.procedure;

export const protectedProcedure = t.procedure.use(({ ctx, next }) => {
  if (!ctx.user) throw new TRPCError({ code: "UNAUTHORIZED" });
  return next({ ctx: { ...ctx, user: ctx.user } });
});

export function roleProcedure(...roles: Role[]) {
  return protectedProcedure.use(({ ctx, next }) => {
    if (!roles.includes(ctx.user.role)) throw new TRPCError({ code: "FORBIDDEN" });
    return next({ ctx });
  });
}

export function tenantTx<T>(ctx: TRPCContext, fn: Parameters<typeof withTenant<T>>[1]) {
  if (!ctx.user) throw new TRPCError({ code: "UNAUTHORIZED" });
  return withTenant(ctx.user.tenantId, fn);
}
```

```typescript
import type { BatchStatus } from "@prisma/client";

const SEQUENCE: BatchStatus[] = ["planificado", "pesado", "mezclado", "envasado", "calidad"];
const TERMINAL: BatchStatus[] = ["liberado", "rechazado"];

export function nextStage(current: BatchStatus): BatchStatus | null {
  const idx = SEQUENCE.indexOf(current);
  if (idx === -1 || idx === SEQUENCE.length - 1) return null;
  return SEQUENCE[idx + 1];
}

export function canTransition(from: BatchStatus, to: BatchStatus): boolean {
  if (TERMINAL.includes(from)) return false;
  if (from === "calidad") return to === "liberado" || to === "rechazado";
  return nextStage(from) === to;
}
```

```typescript
export const productionRouter = router({
  list: roleProcedure("jefe_planta", "calidad", "director_tecnico", "operario", "admin").query(({ ctx }) =>
    tenantTx(ctx, (tx) => tx.productionOrder.findMany({ orderBy: { createdBy: "asc" }, include: { formula: true } })),
  ),
  getById: roleProcedure("jefe_planta", "calidad", "director_tecnico", "operario", "admin")
    .input(z.object({ id: z.string().uuid() }))
    .query(({ ctx, input }) =>
      tenantTx(ctx, (tx) =>
        tx.productionOrder.findUniqueOrThrow({
          where: { id: input.id },
          include: { formula: true, events: { orderBy: { occurredAt: "asc" } }, signatures: true, deviations: true },
        }),
      ),
    ),
  create: roleProcedure("jefe_planta")
    .input(z.object({ formulaId: z.string().uuid(), plannedQuantity: z.number().positive(), plannedStart: z.string().optional() }))
    .mutation(({ ctx, input }) =>
      tenantTx(ctx, async (tx) => {
        const formula = await tx.masterFormula.findUniqueOrThrow({ where: { id: input.formulaId } });
        if (formula.status !== "active") throw new TRPCError({ code: "BAD_REQUEST", message: "Solo formulas activas pueden usarse" });
        const orderNumber = await generateOrderNumber(ctx.user.tenantId);
        return tx.productionOrder.create({
          data: {
            tenantId: ctx.user.tenantId,
            orderNumber,
            formulaId: formula.id,
            formulaVersion: formula.version,
            plannedQuantity: input.plannedQuantity,
            plannedStart: input.plannedStart ? new Date(input.plannedStart) : undefined,
            createdBy: ctx.user.id,
            status: "planificado",
          },
        });
      }),
    ),
});

export async function advanceStageInternal(
  tx: Parameters<Parameters<typeof tenantTx>[1]>[0],
  orderId: string,
  to: Parameters<typeof canTransition>[1],
) {
  const order = await tx.productionOrder.findUniqueOrThrow({ where: { id: orderId } });
  if (!canTransition(order.status, to)) {
    throw new TRPCError({ code: "BAD_REQUEST", message: `No se puede pasar de ${order.status} a ${to}` });
  }
  return tx.productionOrder.update({ where: { id: orderId }, data: { status: to } });
}
```

```typescript
    .input(z.object({

    }))
```

```typescript
      tenantTx(ctx, (tx) =>
        tx.qcResult.create({
          data: { tenantId: ctx.user.tenantId, ...input, recordedBy: ctx.user.id },
        }),
      ),
    ),
  release: roleProcedure("director_tecnico")
    .input(z.object({ productionOrderId: z.string().uuid() }))
    .mutation(({ ctx, input }) =>
      tenantTx(ctx, async (tx) => {
        const failing = await tx.qcResult.findMany({ where: { productionOrderId: input.productionOrderId, result: "fail" } });
        const openDeviations = await tx.deviation.findMany({ where: { productionOrderId: input.productionOrderId, status: { not: "cerrada" } } });
        if (failing.length > 0) throw new Error("Hay resultados de QC en fail — no se puede liberar");
        if (openDeviations.length > 0) throw new Error("Hay desviaciones abiertas — no se puede liberar");
        return advanceStageInternal(tx, input.productionOrderId, "liberado");
      }),
    ),
});
```

```typescript
import { db, type PendingEvent } from "./db";

export async function queueEvent(event: PendingEvent): Promise<void> {
  await db.pendingEvents.add(event);
}

export async function syncPendingEvents(): Promise<{ pushed: number; duplicates: number }> {
  const pending = (await db.pendingEvents.toArray()).filter((e) => !e.pushedAt);
  if (pending.length === 0) return { pushed: 0, duplicates: 0 };

  const res = await fetch("/api/sync/events", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ events: pending }),
  });
  if (!res.ok) return { pushed: 0, duplicates: 0 };

  const body = await res.json();
  let pushed = 0;
  let duplicates = 0;
  for (const r of body.results as { clientEventId: string; status: "accepted" | "duplicate" }[]) {
    await db.pendingEvents.update(r.clientEventId, { pushedAt: new Date().toISOString() });
    if (r.status === "accepted") pushed++;
    else duplicates++;
  }
  return { pushed, duplicates };
}
```

```typescript
import { NextResponse } from "next/server";
import { z } from "zod";
import { getCurrentUser } from "@/lib/auth";
import { withTenant } from "@/lib/db";

const eventSchema = z.object({
  clientEventId: z.string().uuid(),
  productionOrderId: z.string().uuid(),
  eventType: z.string(),
  payload: z.unknown(),
  occurredAt: z.string(),
  deviceId: z.string(),
});
const bodySchema = z.object({ events: z.array(eventSchema) });

export async function POST(req: Request) {
  const user = await getCurrentUser();
  if (!user) return NextResponse.json({ success: false }, { status: 401 });

  const parsed = bodySchema.parse(await req.json());

  await withTenant(user.tenantId, (tx) =>
    tx.batchEvent.createMany({
      data: parsed.events.map((e) => ({
        tenantId: user.tenantId,
        productionOrderId: e.productionOrderId,
        eventType: e.eventType,
        payload: e.payload as any,
        actorUserId: user.id,
        occurredAt: new Date(e.occurredAt),
        clientEventId: e.clientEventId,
        deviceId: e.deviceId,
      })),
      skipDuplicates: true,
    }),
  );

  return NextResponse.json({
    success: true,
    results: parsed.events.map((e) => ({ clientEventId: e.clientEventId, status: "accepted" as const })),
  });
}
```

Note: `skipDuplicates: true` relies on `client_event_id`'s `@unique` constraint from Task 2 — a retried batch never errors and never double-inserts. The response always reports `"accepted"` per event because Prisma's `createMany` doesn't report per-row conflict outcomes; this matches the blueprint's "never error destructively" rule (a true duplicate is silently absorbed, not surfaced as a failure).

```typescript
export const traceabilityRouter = router({
  byRawMaterialLot: roleProcedure("calidad", "director_tecnico")
    .input(z.object({ rawMaterialLotId: z.string().uuid() }))
    .query(async ({ ctx, input }) => {
      const events = await tenantTx(ctx, (tx) =>
        tx.batchEvent.findMany({ where: { eventType: "weighing" } }),
      );
      const matches = events.filter((e: any) => e.payload?.rawMaterialLotId === input.rawMaterialLotId);
      return [...new Set(matches.map((e: any) => e.productionOrderId))];
    }),
  byFinishedLot: roleProcedure("calidad", "director_tecnico")
    .input(z.object({ finishedProductLotId: z.string().uuid() }))
    .query(({ ctx, input }) =>
      tenantTx(ctx, async (tx) => {
        const finished = await tx.finishedProductLot.findUniqueOrThrow({ where: { id: input.finishedProductLotId } });
        const events = await tx.batchEvent.findMany({
          where: { productionOrderId: finished.productionOrderId, eventType: "weighing" },
        });
        return events.map((e: any) => e.payload?.rawMaterialLotId).filter(Boolean);
      }),
    ),
});
```

```typescript
import type { PrismaClient } from "@prisma/client";
import { Prisma } from "@prisma/client";

const REGULATED_MODELS = new Set(["ProductionOrder", "BatchEvent", "QcResult", "Deviation", "FinishedProductLot"]);
const WRITE_OPS = new Set(["create", "update", "delete", "createMany", "updateMany", "deleteMany"]);

export function withAuditLog(prisma: PrismaClient, actorUserId: string, tenantId: string) {
  return prisma.$extends({
    query: {
      $allModels: {
        async $allOperations({ model, operation, args, query }) {
          const result = await query(args);
          if (model && REGULATED_MODELS.has(model) && WRITE_OPS.has(operation)) {
            await (prisma as any).auditLog.create({
              data: {
                tenantId,
                tableName: model,
                recordId: (result as any)?.id ?? "unknown",
                action: operation,
                afterData: result as unknown as Prisma.InputJsonValue,
                actorUserId,
                occurredAt: new Date(),
              },
            });
          }
          return result;
        },
      },
    },
  });
}
```

```typescript
import { chromium } from "playwright";

export function renderBatchRecordHtml(order: {
  orderNumber: string;
  status: string;
  signatures: { stage: string; signedBy: string; meaningStatement: string; signedAt: string }[];
  qcResults: { parameter: string; measuredValue: number; result: string }[];
  events: { eventType: string; occurredAt: string; actorUserId: string }[];
}): string {
  return `
    <html><body style="font-family: sans-serif;">
      <h1>Batch Record — ${order.orderNumber}</h1>
      <p>Estado: ${order.status}</p>
      <h2>Firmas</h2>
      <ul>${order.signatures.map((s) => `<li>${s.stage}: ${s.meaningStatement} — ${s.signedBy} (${s.signedAt})</li>`).join("")}</ul>
      <h2>Resultados de calidad</h2>
      <ul>${order.qcResults.map((r) => `<li>${r.parameter}: ${r.measuredValue} (${r.result})</li>`).join("")}</ul>
      <h2>Eventos</h2>
      <ul>${order.events.map((e) => `<li>${e.eventType} — ${e.occurredAt} — ${e.actorUserId}</li>`).join("")}</ul>
    </body></html>
  `;
}

export async function renderPdf(html: string): Promise<Buffer> {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  await page.setContent(html);
  const pdf = await page.pdf({ format: "A4" });
  await browser.close();
  return pdf;
}
```
